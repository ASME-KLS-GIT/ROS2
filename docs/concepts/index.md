# Concepts

Short, focused explanations of the ideas that everything else in ROS2 is
built on. Read these before the examples — the code will make a lot more
sense once you have the mental model.

- [Nodes & Topics](nodes-and-topics.md) — the basic unit of computation in
  ROS2, and how nodes talk to each other without knowing about each other.

More concept guides (services & actions, parameters, launch files,
lifecycle nodes, QoS) are on the roadmap — see the project README if
you'd like to help write one.
