# Examples

Minimal, working ROS2 programs. Every example here has a matching package
under `examples/` in the repo, and that package is built and run in CI on
every change — the code shown on the page is the exact code that gets
tested, via an include, not a copy that can drift out of sync.

- [Publisher & Subscriber](publisher-subscriber.md) — the "hello world" of
  ROS2: one node that publishes a string on a timer, one node that
  subscribes and logs what it hears.

More examples (services & clients, custom messages, launch files,
parameters) are on the roadmap.
